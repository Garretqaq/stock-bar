# StockBar 使用指南

[返回 README](../README.md)

## 主面板操作

| 操作 | 结果 |
| --- | --- |
| 左键点菜单栏 / 托盘图标 | 打开主面板：三只大盘指数、搜索、自选列表与分时图 |
| 再点一次图标，或点窗口外 | 收起主面板 |
| `Esc` | 收起主面板；光标在搜索框里时只清空搜索；右键菜单打开时只关闭菜单 |
| 点大盘卡片或自选行 | 展开 / 收起该标的的分时图；大盘指数还会显示当日成交额，以及与上一日同一时刻相比的增减 |
| 自选行右键 | 删除自选、从菜单栏显示中移除，或移入某个分组（建过分组后才出现） |
| 菜单栏 / 托盘图标右键 | 退出 StockBar |
| 主面板顶部 / 底部 | 刷新、打开设置、切换刷新间隔（3 / 5 / 10 / 30 秒）、退出 |

搜索支持代码、名称与拼音，选中结果即加入自选。内置的大盘指数为上证指数、深证成指与创业板指。

## 设置窗口

设置窗口分为三页：

- **仪表盘**：调整菜单栏（Windows 为悬浮行情条）的样式、显示字段、涨跌着色与标的顺序，拖动即可排序，上方提供实时预览。
- **行情**：搜索添加自选、拖动左侧把手排序、行尾按钮置顶、勾选后批量加入 / 移出菜单栏、批量移入分组或删除，以及右键增删菜单栏标的；自选按分组分区显示，右键行可移入分组，右键分组标题可重命名、上移下移或删除分组。
- **设置**：选择跟随系统 / 浅色 / 深色主题、红涨绿跌 / 绿涨红跌，以及刷新间隔。

### 显示样式

- **单行文字**：默认图标加行情文字。
- **双行紧凑**：名称与行情分两行，可按涨跌着色。macOS 不着色时按 template 图处理，自动适配深浅色菜单栏。
- **仅图标**：只保留图标，不展示行情文字；Windows 此时不显示悬浮行情条。

名称、价格与涨跌幅按需勾选。大盘指数与自选共用菜单栏的 **3 个名额**。

### 置顶与排序

置顶只改变自选列表顺序，不占用额外的菜单栏名额，也不等同于加入菜单栏显示。置顶区始终位于列表最前，拖动排序只能在置顶区或非置顶区各自内部进行。

### 自选分组

自选多了可以分组管理：「行情」页右上角的「＋ 新建分组」建组，建好就地改名；右键某一行可把它移入某个分组，也可以勾选多只后用操作条上的「移入分组」批量搬（大盘指数不能分组）。右键分组标题可重命名、上移下移或删除分组；删除分组只把成员回落到「未分组」，自选一只都不会少。

建过分组之后，主面板的搜索框下方会出现分组筛选条（全部 / 未分组 / 各分组），点一下就只看那个分组；在某个分组里搜索添加的标的会直接进这个分组。列表行上的分组名标签只在「全部」里显示。

分组只影响自选的查看方式：菜单栏（Windows 为悬浮行情条）仍是一个跨分组、最多 3 个标的的有序集合，置顶也仍然是自选列表范围内的事。

## 平台差异

| 项目 | macOS | Windows | Linux |
| --- | --- | --- | --- |
| 行情展示 | 菜单栏：图标加文字，或双行紧凑图片 | 托盘 tooltip 加桌面悬浮行情条 | 托盘；展示能力取决于桌面环境，无 Windows 悬浮行情条 |
| 图标适配 | template 图标自动适配系统深浅色 | 按任务栏深浅色换白 / 黑 | 取决于桌面环境 |
| 设置窗口 | 无边框，自绘红绿灯与拖动区 | 原生标题栏，Windows 11 设置风格 | 沿用非 Windows 布局 |
| 打包 | 本地 `pnpm app:build` | 本地打包或 GitHub Actions | 本地打包，需满足 Tauri 系统依赖 |

Windows 托盘不能展示长行情文字，因此使用可拖动的悬浮行情条。点击行情条可在旁边打开主面板，悬停托盘图标也可查看行情提示。

## 数据来源与市场标识

行情来自东方财富公开接口：

- 批量报价：`ulist.np`。
- 分时数据：`trends2`。大盘指数多取一天，用来算「较上一日同期」的成交额增减。
- 股票搜索：`suggest`。搜索接口不提供 CORS 头，因此通过 JSONP 调用。

接口返回 `"-"` 时表示无数据，界面统一显示 `--`。无需注册或 API Key；数据准确性、延迟和接口可用性取决于数据源。

`secid` 的格式为 `市场代码.证券代码`，用于接口请求，不需要用户手工输入：

| 前缀 | 市场 | 示例 |
| --- | --- | --- |
| `1` | 上交所 | `1.600519` |
| `0` | 深交所；代码以 8 / 4 / 92 开头时按北交所识别 | `0.000001` |
| `116` | 港股 | `116.00700` |
| `105` / `106` / `107` | 美股 | `105.NVDA` |
| `100` | 海外指数 | `100.NDX` |

### 交易状态

按各市场时区判断交易时段。没有节假日日历，而是结合报价里的最后成交时间推断：工作日开盘 10 分钟后，最后成交仍不在当天，就显示「休市」。开盘前无法提前得知当天是否休市。

## 开发补充

单元测试使用 Vitest（happy-dom 环境），覆盖接口解析、菜单栏内容生成、设置读写与迁移、右键菜单及拖动计算。

Vite 开发端口固定为 **1420**（`strictPort`），与 `src-tauri/tauri.conf.json` 中的 `devUrl` 对应；修改端口时必须同步修改两处。目录结构、跨窗口同步与平台实现约定见 [AGENTS.md](../AGENTS.md)。
