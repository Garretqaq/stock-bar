# StockBar 使用指南

[返回 README](../README.md) · [开发指南](development.md)

## 主面板操作

| 操作 | 结果 |
| --- | --- |
| 左键点菜单栏 / 托盘图标 | 打开主面板：三只大盘指数、搜索、自选列表与分时图 |
| 再点一次图标，或点窗口外 | 收起主面板 |
| `Esc` | 收起主面板；光标在搜索框里时只清空搜索；右键菜单打开时只关闭菜单 |
| 点大盘卡片或自选行 | 展开 / 收起该标的的分时图；大盘指数还会显示当日成交额，以及与上一日同一时刻相比的增减 |
| 自选行右键 | 置顶 / 取消置顶、删除自选、从菜单栏显示中移除，或移入某个分组（建过分组后才出现） |
| 搜索结果右键 | 把搜到的标的加入自选、或直接加进某个分组；已经在自选里的还能移入别的分组、置顶 / 取消置顶 |
| 菜单栏 / 托盘图标右键 | 退出 StockBar |
| 主面板顶部 / 底部 | 刷新、打开设置、切换刷新间隔（3 / 5 / 10 / 30 秒）、退出 |

搜索支持代码、名称与拼音，左键点结果即加入自选，右键还能直接加进某个分组、或给已有的自选换分组与置顶（结果列表不会因此收起，方便连着整理几只）。内置的大盘指数为上证指数、深证成指与创业板指。

## 设置窗口

设置窗口分为五页：

- **仪表盘**：调整菜单栏（Windows 为悬浮行情条）的样式、显示字段、涨跌着色与标的顺序，拖动即可排序，上方提供实时预览。
- **行情**：搜索添加自选、拖动左侧把手排序、行尾按钮置顶、勾选后批量加入 / 移出菜单栏、批量移入分组或删除，以及右键增删菜单栏标的；自选按分组分区显示，右键行可移入分组，分组标题右侧的「⋯」（右键标题同样可以）可重命名、上移下移或删除分组。搜索结果也能右键：一次就把标的加进自选或直接加进某个分组，已经在自选里的还能换分组、置顶。
- **MCP**：让支持 MCP 的 AI 客户端改自选与分组（见「用 MCP 配置自选」），页面上可以看本地桥状态、复制客户端配置，也能一键开关 MCP（默认关闭）。
- **设置**：选择跟随系统 / 浅色 / 深色主题、红涨绿跌 / 绿涨红跌，以及刷新间隔与数据来源。
- **关于**：显示当前版本，手动检查新版本、一键下载安装（装完自动重启），以及「启动时自动检查更新」开关。主面板顶栏下的更新提示条也直接跳到这一页。

### 显示样式

- **单行文字**：默认图标加行情文字。
- **双行紧凑**：名称与行情分两行，可按涨跌着色。macOS 不着色时按 template 图处理，自动适配深浅色菜单栏。
- **仅图标**：只保留图标，不展示行情文字；Windows 此时不显示悬浮行情条。

名称、价格与涨跌幅按需勾选。大盘指数与自选共用菜单栏的 **3 个名额**。

### 置顶与排序

置顶只改变自选列表顺序，不占用额外的菜单栏名额，也不等同于加入菜单栏显示。置顶区始终位于列表最前，用浅底色标出、与其余自选之间画一道分界；拖动排序只能在置顶区或非置顶区各自内部进行。在主面板右键自选行即可置顶或取消（设置窗口「行情」页的行尾按钮与它等效）。

### 自选分组

自选多了可以分组管理：「行情」页右上角的「＋ 新建分组」建组，建好就地改名；右键某一行可把它移入某个分组，也可以勾选多只后用操作条上的「移入分组」批量搬（大盘指数不能分组）。搜索结果里还没加进来的标的也能右键「加入并移入「X」」，省掉「先加入、再去列表里搬一次」；已经是自选的则直接给「移入「X」」与置顶。分组标题右侧的「⋯」按钮（右键标题也一样）提供重命名、上移下移与删除；删除分组会先就地确认一次，并说明成员会回到「未分组」—— 删除只把成员回落过去，自选一只都不会少。

建过分组之后，主面板的搜索框下方会出现分组筛选条（全部 / 未分组 / 各分组），点一下就只看那个分组；在某个分组里搜索添加的标的会直接进这个分组。列表行上的分组名标签只在「全部」里显示。分组多到一行放不下时，筛选条可以横向滑动（滚轮、按住拖动都行），末尾会多出一个 ☰ 按钮，点它会把全部分组摊成一片和筛选条上一模一样的标签（带数量，当前这个高亮），直接点就能切过去。

分组只影响自选的查看方式：菜单栏（Windows 为悬浮行情条）仍是一个跨分组、最多 3 个标的的有序集合，置顶也仍然是自选列表范围内的事。

## 平台差异

| 项目 | macOS | Windows | Linux |
| --- | --- | --- | --- |
| 行情展示 | 菜单栏：图标加文字，或双行紧凑图片 | 托盘 tooltip 加桌面悬浮行情条 | 托盘；展示能力取决于桌面环境，无 Windows 悬浮行情条 |
| 图标适配 | template 图标自动适配系统深浅色 | 按任务栏深浅色换白 / 黑 | 取决于桌面环境 |
| 设置窗口 | 无边框，自绘红绿灯与拖动区 | 原生标题栏，Windows 11 设置风格 | 沿用非 Windows 布局 |
| 打包 | 本地 `pnpm app:build` | 本地打包或 GitHub Actions | 本地打包，需满足 Tauri 系统依赖 |

Windows 托盘不能展示长行情文字，因此使用可拖动的悬浮行情条。点击行情条可在旁边打开主面板，悬停托盘图标也可查看行情提示。

## 数据来源与市场标识

报价与分时支持东方财富和腾讯公开接口，在设置 →「设置」→「数据来源」中选择：

- **自动**（默认）：优先东方财富，请求失败时尝试腾讯。
- **东方财富**：固定使用东方财富。
- **腾讯**：固定使用腾讯。

自动切换适用于报价与分时；股票搜索始终使用东方财富，不会随数据源选择切换。不同数据源的标的覆盖和统计口径可能不同。

东方财富接口：

- 批量报价：`ulist.np`。
- 分时数据：`trends2`。大盘指数多取一天，用来算「较上一日同期」的成交额增减。
- 股票搜索：`suggest`。搜索接口不提供 CORS 头，因此通过 JSONP 调用。

腾讯接口：报价使用 `qt.gtimg.cn`，分时使用 `web.ifzq.gtimg.cn`。

指数分时面板还会展示全市场成交情况：当日总额按沪 + 深 + 北统计，与上一交易日同一时刻的对比只使用沪深两市口径。缺少任一市场的必要数据时，不会将剩余部分当作完整总额；缺少可比历史数据时不显示完整同期对比。

接口返回 `"-"` 时表示无数据，界面统一显示 `--`。无需注册或 API Key；数据准确性、延迟和接口可用性取决于数据源。

`secid` 的格式为 `市场代码.证券代码`，用于接口请求，不需要用户手工输入：

| 前缀 | 市场 | 示例 |
| --- | --- | --- |
| `1` | 上交所 | `1.600519` |
| `0` | 深交所；代码以 8 / 4 / 92 开头时按北交所识别 | `0.000001` |
| `116` | 港股 | `116.00700` |
| `105` / `106` / `107` | 美股 | `105.NVDA` |
| `100` | 海外指数 | `100.NDX` |

### 交易状态

按各市场时区判断交易时段。没有节假日日历，而是结合报价里的最后成交时间推断：工作日开盘 10 分钟后，最后成交仍不在当天，就显示「休市」。开盘前无法提前得知当天是否休市。

## 用 MCP 配置自选

除了在界面上点，也可以让支持 MCP 的 AI 客户端（Claude Code、Claude Desktop 等）改自选与分组。直接说一句话就行：

- 「把宁德时代加到自选，放进持仓分组」
- 「新建分组叫打新，把这几只挪进去」
- 「看看我自选分了哪些组，各放了什么」

前提：

- **StockBar 正在运行**（macOS 菜单栏 / Windows 托盘有图标）。MCP 服务不直接改存储，而是把命令交给运行中的应用，由应用用与界面相同的规则执行；改完界面与菜单栏立即同步，不用重启。
- 需要 Node 22+，并在 MCP 客户端里把命令指向 `mcp/stockbar-mcp.mjs`：安装包自带一份，**设置窗口左侧的「MCP」页**能直接复制这段配置，同时显示本地桥的端口与是否就绪；自己 clone 的仓库版本（路径指向仓库里的 `mcp/stockbar-mcp.mjs`）同样能用。想本地调试可以直接 `pnpm mcp` 跑起来。
- **开关默认是关的**：要用先去设置窗口左侧的「MCP」页打开一次。关着的时候本地桥不监听端口、连接信息文件也不存在（等于这个功能不存在），AI 客户端会收到「没找到 StockBar 的运行信息」；打开后是新端口，客户端不用改配置，开关状态存在应用设置里、重启后保持。

能做的事：查看自选与分组、按代码 / 名称 / 拼音搜索标的、加入与移除自选、调整顺序、置顶与取消置顶、新建 / 改名 / 删除 / 排序分组、把自选移进或移出分组。大盘指数是内置的，不能通过 MCP 增删。

报错怎么读：

| 提示 | 原因与处理 |
| --- | --- |
| 没找到 StockBar 的运行信息 | 应用没在运行，或设置里的 MCP 开关被关掉了：先启动 StockBar / 打开开关 |
| 运行信息已过期（令牌对不上） | 应用刚重启过：重试一次即可 |
| 没有「X」这个分组 | 名字写错了，或还没建：先新建分组 |
| 「X」匹配到多只标的 | 名称不唯一：用搜索给出的 secid 再说一次 |
| 查不到 X 的行情 | 代码或市场不对：换成正确的 secid |

## 应用内更新

启动时会检查 GitHub Release 上的 `latest.json`，发现新版本后在主面板顶栏下显示提示。点击提示可打开设置 →「关于」，一键下载安装；该页也支持手动检查和关闭「启动时自动检查更新」。自动检查不会自行安装。

更新包须通过发布者公钥的签名校验才会安装：

- macOS 使用 `.app.tar.gz` 替换应用，安装位置需要可写，建议拖入 `/Applications`；请勿在只读 DMG 内运行。
- Windows 使用 NSIS 安装包，安装时显示进度窗口，安装器会让应用退出。

安装完成后应用会重启，Windows 由安装器处理退出流程。macOS 包未做系统签名与公证；如果更新后再次被拦截，可右键「打开」，或执行：

```bash
xattr -dr com.apple.quarantine /Applications/StockBar.app
```

应用内更新只读取已公开的最新 Release，草稿期间不会对用户生效。

## 开发补充

单元测试使用 Vitest：`src/` 下的用例跑在 happy-dom 环境，覆盖接口解析、菜单栏内容生成、设置读写与迁移、右键菜单、拖动计算与 MCP 命令处理；`mcp/` 下的用例跑在 node 环境，覆盖 MCP 服务（含一条真的起进程、配假本地桥的端到端用例）。

Vite 开发端口固定为 **1420**（`strictPort`），与 `src-tauri/tauri.conf.json` 中的 `devUrl` 对应；修改端口时必须同步修改两处。目录结构、跨窗口同步与平台实现约定见 [AGENTS.md](../AGENTS.md)。
